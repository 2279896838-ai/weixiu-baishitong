# 一、作品信息与选题依据

| 项目 | 内容 |
| --- | --- |
| 赛道 / 题目 | 智能制造赛道 / 维修百事通——设备故障诊断知识助手 |
| 团队 / 作品 | 智冶设备智维队 / 维修百事通——智能冶金设备故障诊断与点检智能体 |
| 推荐命名 | 智造·维修百事通·智冶设备智维队·冶金设备智能运维助手 |
| 依托单位 | 日照职业技术大学 智能冶金系（工业互联网方向） |
| 应用场景 | 智能冶金系实训中心设备运维、工业互联网课程实训、日照区域中小企业设备班组 |

**选题依据**：智能制造赛道聚焦“中小企业设备维护依赖老师傅经验、实训车间手册与案例分散”的共性痛点。智能冶金系实训中心拥有车床、加工中心、3D 打印、激光、空压机、电机、配电柜、连铸机、加热炉、轧机、除尘风机、液压站、电弧炉、球磨机、回转窑、浓密机等 16 台典型设备，设备说明书、维修手册、教师口述案例与点检记录分散在纸质资料和个人经验中，学生遇到问题时检索慢、步骤不统一、处置难闭环。

本项目把“设备手册 + 教师访谈 + 点检异常 + 工单结案”沉淀为可检索知识库，用智能体把**故障问答、排查引导、点检填报、异常看板、工单流转、知识回流**串成闭环，定位为“智能冶金系设备运维教学与实训工具”，并形成可复制到区域中小企业的低成本方案。

**作品摘要**：以 107 条结构化知识、5 棵诊断树、119 项点检和 6 个智能体工具为核心，提供“问—查—检—单—回”的完整设备运维闭环；支持本机服务、离线单文件与 GitHub Pages 三种演示形态，模型异常时自动回退离线检索，适合实训现场与答辩演示。

**作品形态与关键词**：

| 作品形态 | 智能体 + 工作流 + 知识库 + 应用原型 |
| --- | --- |
| 关键词 | 设备运维、知识库、RAG、智能体、点检闭环、离线部署、安全优先 |
| 与赛道契合 | 面向实训车间与中小企业设备维护，把“老师傅经验”转化为可检索、可追溯、可复用的知识资产 |
| 当前阶段 | 基础档功能全部完成，进阶档完成诊断树、多轮追问、工单回流、精致界面与离线演示 |

**核心问题**：不是“做一个会聊天的机器人”，而是把设备知识、排查规则、点检标准与工单闭环固化为可教学、可复制的智能体工作流；回答必须可核验，危险操作必须先停机断电。

# 二、需求分析与调研方法

**现场痛点**：

- 设备手册、维修手册、故障案例分散，学生检索依赖教师口头指点；
- 新学生排查步骤不统一，安全确认容易被跳过；
- 点检记录停留在纸面，异常、工单与知识沉淀没有闭环；
- 通用大模型直接回答设备问题容易编造参数、引用不可追溯，不能直接用于现场；
- 工业互联网专业需要“设备数据 + 智能体”的落地载体，把采集、诊断、处置与知识沉淀串起来。

**调研方法**：

1. 设备台账梳理：按实训设备与智能冶金设备分类，整理 16 台设备、7 类实训 + 9 类智能冶金；
2. 教师访谈：围绕常见故障、判断依据、处置步骤、安全禁忌进行半结构化访谈，形成 9 条教师口述案例；
3. 手册整理：从设备说明书、维修手册公开章节整理结构化知识；
4. 工单复盘：从点检异常与维修记录提取根因、处置与验证方法；
5. 现场验证：在实训室进行问答、点检、看板、工单流程演示，按反馈迭代提示词与界面。

**需求边界**：当前聚焦“知识诊断 + 点检 + 工单 + 知识回流”，不直接控制设备、不替代教师现场判断；涉及带电、带压、旋转、高温熔融金属、煤气等危险操作时，系统只给出停机、断电、撤离、转人工路径，不提供危险拆检步骤。

**调研样本与访谈提纲**：

| 对象 | 样本 | 重点问题 |
| --- | --- | --- |
| 实训学生 | 3 个班级试点 | 遇到故障先问谁、最怕哪一步、点检表是否好用 |
| 指导教师 / 设备管理员 | 智能冶金系教师与管理员 | 常见故障、判断依据、安全禁忌、知识如何复核 |
| 企业设备班组（拟） | 区域中小企业访谈 | 点检标准化、老师傅经验留存、低成本部署 |

**需求优先级**：P0 为故障问答、点检清单、安全拦截；P1 为异常看板、工单闭环、知识回流；P2 为工艺计算、工业互联网数据接口与多模态扩展。

# 三、目标用户与业务闭环

| 用户 | 典型场景 | 获得的价值 |
| --- | --- | --- |
| 智能冶金系实训学生 | 描述故障现象、按引导排查、完成点检 | 按标准步骤排查，先安全后操作，理解“数据—知识—智能体—现场”链路 |
| 教师 / 设备管理员 | 审核知识、查看异常看板、派发与结案工单 | 掌握设备状态，减少重复口头指导，沉淀教学案例 |
| 工业互联网专业学生 | 智能体工具编排、知识库维护、部署运维 | 真实项目式学习载体，覆盖采集、检索、部署、测试 |
| 区域中小企业设备班组 | 点检标准化、故障经验留存、维修闭环 | 低成本设备运维数字化起步，不依赖昂贵平台 |

**业务闭环**：学生描述现象 → 智能体路由到知识诊断 / 排查引导 / 点检 / 看板 / 工单 / 工艺计算工具 → 输出原因排序、判定依据、处置步骤、风险与引用 → 点检异常汇总 → 创建工单 / 结案 → 根因与处置进入知识候选池 → 教师复核后回流知识库。

**典型输出**：故障问答给出“最可能原因 + 验证方法 + 处置步骤 + 风险 + 引用”；排查引导先做安全确认，再逐轮提问；点检异常自动进入看板；工单结案形成可复用的维修案例。

**关键用户旅程**：

| 阶段 | 学生动作 | 系统支持 | 产出 |
| --- | --- | --- | --- |
| 发现异常 | 描述现象、设备与报警 | 意图识别、设备/类别匹配、安全预检 | 故障问答/排查入口 |
| 诊断排查 | 按引导回答问题、做安全检查 | 决策树逐轮追问、安全确认门 | 原因排序、验证方法、处置步骤 |
| 点检处置 | 生成并填写点检清单 | 点检模板、异常备注、看板统计 | 点检记录、异常单 |
| 工单复盘 | 建单、结案、填写根因 | 工单流转、知识候选池 | 可复用维修案例 |
| 教学沉淀 | 教师复核、课堂复盘 | 知识审核、版本与来源管理 | 更新后的知识库 |

# 五、知识库建设与专业性

| 维度 | 规模与做法 |
| --- | --- |
| 设备台账 | 16 台（7 类实训 + 9 类智能冶金），覆盖车、铣、增材、激光、空压、电机、配电、连铸、加热炉、轧机、除尘、液压、电弧炉、球磨、回转窑、浓密 |
| 知识条目 | 107 条，覆盖 17 类；含 9 条教师口述案例（录音定位、审核字段） |
| 知识结构 | 每条含症状、原因排序、排查判据、处置措施、风险、来源、审核人、生效日期与安全等级 |
| 知识来源 | 教师访谈 9、设备手册样例 86、模板 3、维修工单 9；来源可追溯、双人复核、过期下架不删除 |
| 诊断决策树 | 5 棵 / 63 节点，先安全确认再进入测量与拆检节点 |
| 点检模板 | 119 项，覆盖日/周/月频次；异常项强制填写备注并进入看板 |

**知识样例**：球磨机筒体振动/衬板撞击声 → 优先检查衬板螺栓、衬板翘起与间隙，其次查钢球偏载、齿轮啮合、轴承与地脚；减速箱漏油 → 轴端油封、结合面、呼吸器、油位；浮选机翻花 → 充气量、叶轮/定子、矿浆性质与药剂制度。

**质量控制**：来源、审核人、生效日期、安全等级四要素齐全；教师访谈保留原稿与录音定位；知识不足时不猜测，明确“未命中可靠证据”；危险请求先拦截再转人工。

**数据说明**：当前数据为智能冶金系实训教学样例与公开手册整理，教师访谈已匿名化；不采集企业敏感数据、不使用未经授权资料，落地时替换为系部真实手册与经授权的教师访谈。

**知识分类与访谈流程**：

- 智能冶金设备：球磨机、回转窑、浓密机、连铸机、加热炉、轧机、电弧炉等；
- 实训设备：车床、加工中心、3D 打印、激光、空压机、电机、配电柜、风机、液压站等；
- 通用设备：泵、减速箱、传感器、HMI、工控箱、皮带、筛、破碎等跨专业对象。

| 访谈步骤 | 做法 | 产出 |
| --- | --- | --- |
| 1. 选样 | 选择经验丰富、熟悉安全的教师/管理员 | 访谈名单与授权 |
| 2. 半结构化访谈 | 故障现象、判断依据、处置步骤、禁忌 | 录音/笔记、原始口述 |
| 3. 结构化整理 | 按知识模板拆分原因、判据、动作、风险 | 知识条目草稿 |
| 4. 双人复核 | 教师审核专业内容，学生核对来源与字段 | 入库版本与审核记录 |

| 层级 | 实现 |

| 检索层 | 关键词 BM25 + 512 维字符哈希向量混合召回；类别/设备过滤；跨类别子系统检索；可选远端 Embedding |

**关键设计**：不把大模型当“唯一答案源”，而是“检索 + 领域规则 + 结构化合成”；模型异常、超时或输出不合规时自动回退，保证实训现场可用。知识检索优先按设备类别与子系统匹配，避免“球磨机上下文”污染减速箱、浮选机等跨系统问题。

**智能体工具清单**：

| 工具 | 输入 | 输出 | 安全边界 |
| --- | --- | --- | --- |
| 知识库诊断 | 现象、设备、报警 | 原因排序、判据、步骤、引用 | 证据不足拒答 |
| 排查引导 | 现象、已做检查 | 逐轮问题、安全确认、排查路径 | 未确认安全不进入测量 |
| 点检清单 | 设备、频次 | 电子点检项与判据 | 模板缺失时明确提示 |
| 异常看板 | 时间范围、类别 | 异常分布、设备排行 | 只读统计 |
| 工单流转 | 异常编号、处置 | 工单状态、结案与回流 | 角色/状态约束 |
| 设备台账 | 名称/编码 | 参数、位置、安全规则 | 只读查询 |
| 工艺计算 | 处理量、浓度、密度 | 体积/密度/底流/容积 | 标注简化假设 |

**回答流程**：意图识别 → 设备/类别槽位 → 混合检索 → 原因排序与证据过滤 → 安全校验 → 结构化输出与引用；任何一步失败则回退离线或转人工。

# 七、提示词工程、安全与数据治理

**提示词资产**：系统提示（角色、边界、引用规则）、故障问答（原因排序/判据）、排查引导（逐轮提问/安全门）、点检（项目/频次/判据）、安全（危险请求拦截）、知识抽取（访谈/工单结构化）等，运行时加载并记录版本；提示词变更需回归测试。

**安全约束**：

- 危险请求：带电、带压、旋转部件、高温熔融金属、煤气、有限空间等先拦截，给出停机、断电、撤离、转人工路径；
- 排查引导：未完成安全确认不进入测量/拆检节点；
- 引用校验：回答必须显示来源，证据不足时不猜测；
- 审计与限流：记录请求、工具调用与知识回流，防止滥用。

**数据治理**：仅使用教学样例、公开手册与经同意的教师访谈；教师访谈匿名化；不采集企业敏感数据；模拟数据在文档中注明；上线前由指导教师复核知识条目与安全策略。

**提示词资产与安全分级**：

| 资产 | 作用 | 版本/校验 |
| --- | --- | --- |
| WXBST-SYS-001 | 角色、边界、引用规则 | 运行时加载，回归测试 |
| QA-001 | 故障问答、原因排序 | 评测集回归 |
| TRG-001 | 逐轮提问、安全确认 | 引导流程测试 |
| CHK-001 | 点检项目、频次、判据 | 模板校验 |
| SAFE-001 | 危险请求拦截 | 危险表达集测试 |
| EXT-001 | 教师访谈/工单知识抽取 | 人工复核 |

| 风险级别 | 示例 | 系统响应 |

# 九、创新点、应用价值与建设计划

**创新点**：

1. **领域知识驱动，不是通用问答套壳**：107 条结构化知识、5 棵诊断树、119 项点检，回答有判据、有引用、有安全边界。
2. **诊断—点检—工单—知识回流闭环**：结案根因自动进入候选池，形成“维修—沉淀—复用”的组织记忆。
3. **工艺计算器嵌入智能体**：矿浆体积、密度、浓密机底流、磨机容积本地计算，计算过程可解释。
4. **安全优先的智能体**：危险请求拦截、排查树安全确认门、证据不足拒答、引用校验。
5. **离线优先、低成本可复制**：单文件离线版 + 本地服务 + Docker/nginx，适配实训室与中小企业。

**应用价值**：

- **教学价值**：作为“冶金设备维护”“工业互联网数据采集”“智能体应用开发”等课程的 project-based 案例；支撑 3 个班级试点；
- **管理价值**：点检、异常、工单数据直接用于系部实训室日常管理；教师访谈与知识复核沉淀为教学资源；
- **社会服务**：为日照区域冶金与装备制造中小企业提供低成本设备运维数字化方案；
- **可持续**：每学期更新知识、每季度复盘故障案例；工单结案自动进入知识候选池。
