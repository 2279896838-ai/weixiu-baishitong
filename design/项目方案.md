# 一、作品信息与选题依据

| 项目 | 内容 |
| --- | --- |
| 赛道 / 题目 | 智能制造赛道 / 维修百事通——设备故障诊断知识助手 |
| 团队 / 作品 | 智冶设备智维队 / 维修百事通——智能冶金设备故障诊断与点检智能体 |
| 推荐命名 | 智造·维修百事通·智冶设备智维队·冶金设备智能运维助手 |
| 依托单位 | 日照职业技术大学 智能冶金系（工业互联网方向） |
| 应用场景 | 智能冶金系实训中心设备运维、工业互联网课程实训、日照区域中小企业设备班组 |

**选题依据**：智能制造赛道聚焦“中小企业设备维护依赖老师傅经验、实训车间手册与案例分散”的共性痛点。智能冶金系实训中心拥有车床、加工中心、3D 打印、激光、空压机、电机、配电柜、连铸机、加热炉、轧机、除尘风机、液压站、电弧炉、球磨机、回转窑、浓密机等 16 台典型设备，设备说明书、维修手册、教师口述案例与点检记录分散在纸质资料和个人经验中，学生遇到问题时检索慢、步骤不统一、处置难闭环。

本项目把“设备手册 + 教师访谈 + 点检异常 + 工单结案”沉淀为可检索知识库，用智能体把**故障问答、排查引导、点检填报、异常看板、工单流转、知识回流**串成闭环，定位为“智能冶金系设备运维教学与实训工具”，并形成可复制到区域中小企业的低成本方案。

# 二、目标用户与业务闭环

| 用户 | 典型场景 | 获得的价值 |
| --- | --- | --- |
| 智能冶金系实训学生 | 描述故障现象、按引导排查、完成点检 | 按标准步骤排查，先安全后操作，理解“数据—知识—智能体—现场”链路 |
| 教师 / 设备管理员 | 审核知识、查看异常看板、派发与结案工单 | 掌握设备状态，减少重复口头指导，沉淀教学案例 |
| 工业互联网专业学生 | 智能体工具编排、知识库维护、部署运维 | 真实项目式学习载体，覆盖采集、检索、部署、测试 |
| 区域中小企业设备班组 | 点检标准化、故障经验留存、维修闭环 | 低成本设备运维数字化起步，不依赖昂贵平台 |

**业务闭环**：学生描述现象 → 智能体路由到知识诊断 / 排查引导 / 点检 / 看板 / 工单 / 工艺计算工具 → 输出原因排序、判定依据、处置步骤、风险与引用 → 点检异常汇总 → 创建工单 / 结案 → 根因与处置进入知识候选池 → 教师复核后回流知识库。

# 四、知识库与专业性

| 维度 | 规模与做法 |
| --- | --- |
| 设备台账 | 16 台（7 类实训 + 9 类智能冶金），覆盖车、铣、增材、激光、空压、电机、配电、连铸、加热炉、轧机、除尘、液压、电弧炉、球磨、回转窑、浓密 |
| 知识条目 | 107 条，覆盖 17 类；含 9 条教师口述案例（录音定位、审核字段） |
| 知识结构 | 每条含症状、原因排序、排查判据、处置措施、风险、来源、审核人、生效日期与安全等级 |
| 知识来源 | 教师访谈 9、设备手册样例 86、模板 3、维修工单 9；来源可追溯、双人复核、过期下架不删除 |
| 诊断决策树 | 5 棵 / 63 节点，先安全确认再进入测量与拆检节点 |
| 点检模板 | 119 项，覆盖日/周/月频次；异常项强制填写备注并进入看板 |

**专业性控制**：危险请求（带电、带压、旋转部位、高温熔融金属、煤气等）先拦截并给出停机、断电、撤离、转人工路径；知识不足时不猜测，明确“未命中可靠证据”；所有回答显示引用来源，避免通用大模型编造参数。

**数据说明**：当前数据为智能冶金系实训教学样例与公开手册整理，教师访谈已匿名化；不采集企业敏感数据、不使用未经授权资料，落地时替换为系部真实手册与经授权的教师访谈。

# 五、技术方案与智能体工具

| 层级 | 实现 |
| --- | --- |
| 展示层 | 六页签控制台（智能体问答、点检、看板、工单、知识库、工艺计算）；独立智能体工作台；移动端适配 |
| 智能体层 | 工具路由：知识库诊断、排查引导、点检清单、异常看板、工单流转、设备台账、工艺计算；回答含工具轨迹与引用 |
| 提示词层 | 系统提示、问答、排查、点检、安全、知识抽取等提示词资产；运行时加载并记录版本 |
| 检索层 | 关键词 BM25 + 512 维字符哈希向量混合召回；类别/设备过滤；跨类别子系统检索；可选远端 Embedding |
| 数据层 | SQLite WAL（streams/state_store/audit_log/schema_migrations）；JSONL 数据包；审计与备份恢复 |
| 基础设施 | Python 标准库 HTTP 服务；离线单文件；Docker/nginx/systemd 部署；Token 鉴权、/api/ready、/api/metrics |
| 大模型（可选） | 可接入自定义模型 Z（OpenAI 兼容）；异常自动回退离线检索与结构化合成；API Key 仅服务端保存 |

**关键设计**：不把大模型当“唯一答案源”，而是“检索 + 领域规则 + 结构化合成”；模型异常、超时或输出不合规时自动回退，保证实训现场可用。

# 七、创新点与差异化

1. **领域知识驱动，不是通用问答套壳**：107 条结构化知识、5 棵诊断树、119 项点检，回答有判据、有引用、有安全边界。
2. **诊断—点检—工单—知识回流闭环**：结案根因自动进入候选池，形成“维修—沉淀—复用”的组织记忆。
3. **工艺计算器嵌入智能体**：矿浆体积、密度、浓密机底流、磨机容积本地计算，计算过程可解释。
4. **安全优先的智能体**：危险请求拦截、排查树安全确认门、证据不足拒答、引用校验。
5. **离线优先、低成本可复制**：单文件离线版 + 本地服务 + Docker/nginx，适配实训室与中小企业。

# 八、应用价值与建设计划

- **管理价值**：点检、异常、工单数据直接用于系部实训室日常管理；教师访谈与知识复核沉淀为教学资源。

- **可持续**：每学期更新知识、每季度复盘故障案例；工单结案自动进入知识候选池。
