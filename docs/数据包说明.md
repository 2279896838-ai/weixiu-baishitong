# 维修百事通数据包说明

本数据包是“维修百事通”MVP 的离线知识底座，供检索问答、排查引导、点检生成与评测使用。全部文件为 UTF-8 无 BOM 编码，JSON/JSONL 均可被 Python 标准库 json 直接解析，不依赖第三方包。

## 1 数据包范围

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| data/equipment.json | 设备台账，7 类实训设备 + 9 类智能冶金设备 | 16 台 |
| data/knowledge.jsonl | 结构化知识条目，一行一条 | 49 条 |
| data/checklists.json | 按设备类别与频次索引的点检模板 | 119 项（D 104、W 15） |
| data/trees.json | 排查决策树 | 5 棵、63 个节点 |
| data/interviews/*.md | 教师口述访谈整理稿 | 3 篇 |
| data/eval_cases*.jsonl | 意图与回答评测用例（基线/工程扩展/冶金） | 76 条（16 + 38 + 22） |

设备编码采用教学编码，形如 EQ-TR01-0001，与真实企业资产编号无关。知识条目编号为 KB-<类别>-<4 位>，点检项编号为 CHK-<类别>-<D/W>-<3 位>，与 MVP 契约一致。

## 2 数据来源

数据来源分四类，每条知识条目的 source 字段均可回溯到具体来源与定位。

1. 系部设备说明书。CK6140 数控车床、VMC850 立式加工中心、FDM 打印机、1000 W 光纤激光切割机、7.5 kW 螺杆空压机、Y2 系列电机、GGD 低压配电柜的随机资料与实训室存档说明书。仅引用书名、页码与章节，不复制全文与图纸。
2. 公开点检模板改编。FDM 工艺参数模板、激光切割参数模板、三相异步电机点检模板，按实训室实际设备与教学安全要求裁剪，来源类型标为 TEMPLATE。
3. 教师口述访谈。2026-09-18 王老师（车工）、2026-09-22 李老师（加工中心）、2026-09-25 张师傅（动力与配电），共 3 场、约 3.7 h 录音。访谈整理稿保留现象、排查步骤、结论与经验，受访人使用化名。
4. 历史工单样例。层错位、电机绝缘低、镜片污染、配电柜焦糊味等 9 条工单，工单号与日期已脱敏重排，仅保留根因、处置与判定标准。
5. 智能冶金扩展（2026-10）。依据连铸机、步进梁式加热炉、热连轧精轧机、布袋除尘风机、AGC 液压站与电弧炉的设备手册（样例）及工艺规程，整理 28 条知识（9 类，其中 ROL 4 条），来源类型标为 MANUAL 或 WORKORDER；数值按工艺卡片口径统一到 mm、MPa、℃、m/min 等单位，落地时替换为系部真实手册与教师访谈。

所有数值均按设备说明书与现场实测口径统一到 mm、MPa、℃、r/min、MΩ 等单位；无法确认的字段不填写推测值。

## 3 采集与转写流程

1. 需求确认：按 16 个设备类别（7 类实训 + 9 类智能冶金）列出待覆盖的故障现象，避免同一现象重复建条。
2. 现场访谈：征得受访人同意后录音，记录时间码与板书；涉及安全阈值时请受访人复述一遍。
3. 逐字转写：访谈后 24 h 内完成转写，保留口语与不确定表述，标注“现场未测”“待核”等字样。
4. 条目抽取：按 WXBST-EXT-001 的口径，一条知识只写一个故障现象，保留原有数值、型号与单位，删除寒暄与免责声明。
5. 结构化：统一 camelCase 字段，causes 按可能性从高到低排序，每条补 basis 与 verifyMethod；checks 写清步骤与量化判据；actions 写安全动作与复测条件。
6. 双人复核：录入人自检后交实训室管理员核对设备部位、阈值与处置，安全相关条目追加安全员会签。
7. 发布与登记：通过后写入 JSONL，登记 id、reviewer、approvedAt、effectiveFrom；修订时保留原 id，更新 approvedAt。

## 4 双人复核与审核字段

复核采用“录入人 + 审核人”双人制。录入人负责来源定位、字段完整与数值单位；审核人负责设备部位真实性、阈值合理性与处置可执行性；securityCritical 为 true 的条目须安全员会签，未会签不得作为 HIGH 置信度依据。

| 字段 | 作用 | 填写规则 |
| --- | --- | --- |
| source.type | 来源类型 | 取 MANUAL、TEMPLATE、TEACHER_INTERVIEW、WORKORDER |
| source.title | 来源名称 | 手册写书名，访谈写“王老师口述 2026-09-18”，工单写工单号与主题 |
| source.locator | 来源定位 | 页码与章节、录音时间段、工单回填栏 |
| reviewer | 审核人 | 实训室管理员；安全相关追加安全员 |
| approvedAt | 审核通过日期 | ISO 日期，本包为 2026-09-24 至 2026-10-16 |
| effectiveFrom | 生效日期 | 与审核通过日期一致，修订时更新 |
| securityCritical | 安全关键标记 | 涉及带电、激光、绝缘、带压的条目为 true |

本包 49 条知识全部完成双人复核，其中 10 条为安全关键条目（KB-LSR-0010、KB-MOT-0018、KB-PWR-0019/0020/0021、KB-CCM-0003、KB-HYD-0001、KB-EAF-0002/0003、KB-ROL-0004），由实训室管理员与安全员双签。复核中发现并修正的问题包括：把“建议”写成“必须”、缺失单位、把工单个例写成通用阈值。

## 5 脱敏与版权说明

1. 受访人使用“王老师、李老师、张师傅”化名，不出现真实姓名、工号与联系方式；录音文件不随数据包发布，仅保留转写稿与时间码。
2. 设备编码、位置、工单号为教学场景编号，已与真实台账脱钩；企业名称、客户信息、真实工艺配方不入库。
3. 设备说明书只引用书名、页码与章节，不复制全文、图表与接线图；公开点检模板为改编使用，已在 source.title 标注“公开版改编”。
4. 数据仅用于教学、竞赛演示与离线评测，不作为真实设备维修依据；现场作业仍以本厂 SOP、设备说明书与教师指令为准。
5. 如来源方对引用范围提出异议，按条目 id 下架并保留修订记录，不删除历史审核信息。

## 7 字段与结构约定

- equipment.json：数组，字段为 equipmentCode、name、category、location、brand、specs、commonFaults、safetyRules。
- knowledge.jsonl：每行一个对象，含 id、title、equipmentCategory、equipmentCodes、symptom、symptomKeywords、causes、checks、actions、risk、source、reviewer、approvedAt、effectiveFrom、securityCritical、tags。
- checklists.json：按类别索引，每类含 D、W 两个数组；每项含 code、name、location、criterion、method、tool、judgment、abnormalAction、frequency、safetyTip。
- trees.json：树对象含 name、equipmentCategory、root、nodes；普通节点含 state、question、options、criterion、action，叶节点含 state、isLeaf、conclusion、actions。
- eval_cases.jsonl：每行含 id、kind、input、expected；expected 含 intent、mustInclude、mustCite、maxCauses。

## 9 后续扩充计划

1. 知识扩容：由 49 条扩到 60 条，补充变频器报警、气动系统、加热炉燃烧、连铸二冷等条目；同一现象按设备型号拆分，保留重复标记。
2. 点检补齐：为 LSR、CMP、MOT 增加 W 档各 5 项，新增 M 档与 Y 档；把绝缘测试、红外测温、力矩复紧等停机项目全部放到 W 档以上。
3. 决策树扩展：在现有 5 棵基础上新增“加热炉炉温不均”“除尘风机振动”“电弧炉炉衬热点”3 棵，节点控制在 8–14 个，统一 S1 安全门。
4. 采集机制：每月安排 1 次教师访谈，工单闭环后由管理员审核生成知识候选，进入 data 前必须双人复核。
5. 质量管理：阈值与说明书版本绑定，每学期复审一次；过期条目下架不删除；新增条目必须带 locator 与 approvedAt。
6. 评测扩充：由 76 条扩到 100 条，增加多轮追问、无命中拒答、越权与危险操作拦截用例，并把智能冶金工艺参数纳入回归。
7. 附件与多模态：为关键条目补充现场照片、振动频谱与红外热像，附件路径写入 tags 或独立清单，不改变现有字段。
