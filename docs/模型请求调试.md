# 模型请求 JSON 落盘说明

系统调用模型服务商（OpenAI 兼容 /chat/completions）时，会把**完整请求 JSON** 和响应/错误 JSON 另存到：

```text
logs/llm-requests/llm-YYYYMMDD-HHMMSS-ffffff.json
```

## 一、文件内容

```json
{
  "savedAt": "2026-11-02T20:29:45+08:00",
  "model": "deepseek-v4.1-flash",
  "url": "https://api.example.com/v1/chat/completions",
  "request": {
    "model": "deepseek-v4.1-flash",
    "messages": [
      { "role": "system", "content": "……完整系统提示词……" },
      { "role": "user", "content": "……完整用户问题……" }
    ],
    "temperature": 0.2,
    "max_tokens": 900,
    "stream": false
  },
  "headers": {
    "Content-Type": "application/json; charset=utf-8",
    "Authorization": "Bearer ***",
    "Accept": "application/json",
    "User-Agent": "wxbst-demo/1.0"
  },
  "stage": "response",
  "response": {
    "choices": [
      { "message": { "content": "……模型返回内容……" } }
    ]
  },
  "error": null
}
```

说明：

- `request` 是发给模型服务商的完整 JSON；
- `response` 是服务商返回的完整 JSON；
- 失败时 `stage=error`，`error` / `responseRaw` 保存错误详情；
- `Authorization` 只保存 `Bearer ***`，**不会落盘 API Key**；
- 默认开启，可用 `LLM_DEBUG_DUMP=0` 关闭；
- 可用 `LLM_DEBUG_DUMP_DIR` 修改目录。

## 二、查看方式

```powershell
# 最新一份请求
Get-ChildItem logs\llm-requests\*.json | Sort-Object LastWriteTime -Descending | Select-Object -First 1
```

```text
# 启动服务时指定目录
set LLM_DEBUG_DUMP_DIR=D:\wxbst-debug
python demo/server.py --port 8787
```

## 三、安全说明

- 只保存请求/响应体，不保存 API Key；
- 若请求/响应中含学生信息或企业内部数据，请按学校数据规范管理日志；
- 生产环境可设置 `LLM_DEBUG_DUMP=0` 关闭，或定期清理。
