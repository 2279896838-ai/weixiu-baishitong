# 网站功能与使用说明

## 一、两个入口

| 入口 | 地址 | 适合场景 |
| --- | --- | --- |
| 控制台 | http://127.0.0.1:8787/ 或 GitHub Pages | 点检、看板、工单、知识库、工艺计算 |
| 智能体问答 | http://127.0.0.1:8787/agent 或离线单文件 | 自然语言问答、工具编排、计算 |

## 二、控制台六页签

1. **智能体问答**：内嵌智能体，支持知识库诊断、排查引导、点检、看板、工单、设备台账与工艺计算。
2. **点检填报**：按设备与频次生成电子点检清单，异常项提交后进入看板。
3. **异常看板**：按类别、设备统计异常与未闭环工单。
4. **工单管理**：由异常创建工单、结案并回流知识候选池。
5. **知识库**：按设备类别、来源、关键词检索；支持“只看安全关键”；条目展开显示原因、判据、处置步骤、风险与来源。
6. **工艺计算**：矿浆体积、矿浆密度、浓密机底流、磨机容积四类计算，输入即算，附公式与说明。

## 三、工艺计算器

### 1. 矿浆体积

[
V = \frac{Q}{C \times \rho}
]

- Q：干矿处理量（t/h）
- C：质量浓度（小数）
- ρ：矿浆密度（t/m³）

### 2. 矿浆密度

[
\frac{1}{\rho} = \frac{C}{\rho_s} + \frac{1-C}{\rho_w}
]

### 3. 浓密机底流

按给矿量：

[
Q_u = \frac{Q_f C_f}{C_u}
]

若输入为溢流量：

[
Q_u = \frac{C_f Q_o}{C_u - C_f}
]

### 4. 磨机所需容积

[
V = \frac{Q}{q}
]

建议再留 10% 余量；q 必须由磨矿试验或同类矿实测确定。

## 四、智能体页

- **右侧工艺计算器**：三种常用计算，输入后立即出结果。
- **清空对话**：一键清空当前会话。
- **示例问题**：连铸、轧机、液压、传感器、HMI 等。
- 回答显示工具调用轨迹、原因排序、处置步骤、风险与引用。

## 五、缓存与更新

- 在线 Pages 更新后如仍显示旧内容，使用带版本参数的链接并 **Ctrl+Shift+R**。
- 本机服务启动：双击“启动维修百事通.bat”或运行 `python demo/server.py --port 8787`。
- 离线单文件：直接双击 `deliverables/维修百事通-离线演示.html`。

## 六、边界

- 计算结果为教学/方案估算，工程应用需用试验数据、流量计与浓度计复核。
- 知识库为实训教学样例，落地时替换为系部真实手册与教师访谈。
- 在线 Pages 为静态离线版，不调用外部大模型；模型 Z 需在后端服务配置。
